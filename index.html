Looking Glass turns an uncertain question into a structured scenario: likely effects, responses, uncertainties, alternative paths, assumptions and confidence ranges. It does not claim to know the future.

This standalone build works without an API key. If you connect your own server endpoint, it can return model-generated analysis without putting a secret key in the browser.

Your endpoint should accept JSON {question, mode, horizon} and return JSON with an answer field. Never put a private provider API key directly in this HTML file.
